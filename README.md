📱 Reduzir para Crescer | Calculadora de Tempo de Tela Infantil

Projeto de Extensão Universitária desenvolvido para a disciplina de Tecnologia Aplicada à Inclusão Digital do Centro Universitário Internacional UNINTER.

💡 Sobre o Projeto

O Reduzir para Crescer é uma ferramenta interativa online criada com o objetivo de conscientizar pais, professores e cuidadores sobre o impacto do tempo de tela no desenvolvimento infantil.

Através de uma interface simples e amigável, a calculadora recebe a idade da criança e o tempo médio diário de exposição às telas (celulares, tablets, TV), cruzando esses dados com as recomendações oficiais da Organização Mundial da Saúde (OMS).

🎯 Objetivos de Desenvolvimento Sustentável (ODS) Atendidos:

🟢 ODS 3: Saúde e Bem-Estar

🔴 ODS 4: Educação de Qualidade

🟡 ODS 12: Consumo e Produção Responsáveis

🛠️ Funcionalidades

Cálculo Personalizado: Análise em tempo real do tempo de tela baseado na idade (0 a 17 anos).

Feedback Visual e Textual: Alertas claros (com ícones e cores) indicando se o tempo está dentro dos limites saudáveis ou se excedeu o recomendado.

Painel Educativo: Uma seção dedicada a explicar as recomendações da OMS de forma resumida e direta.

Design Responsivo: Interface adaptável para funcionar perfeitamente em smartphones, tablets e computadores de mesa.

💻 Tecnologias Utilizadas

A aplicação foi construída com foco em simplicidade, leveza e acessibilidade (arquitetura frontend modular):

HTML5: Estruturação semântica.

Tailwind CSS (via CDN): Estilização ágil, moderna e design responsivo.

CSS3 Customizado: Animações e ajustes de interface.

JavaScript (Vanilla): Lógica de cálculo, manipulação do DOM e validação de dados sem dependência de bibliotecas externas.

FontAwesome: Ícones vetoriais.

Google Fonts: Tipografia (Nunito).
